Check before reporting try rates

"First-try success" and "attempts to full score" are counted per claim ID, which means per phone browser, not per person. They are only reliable if each MW uses one phone and does not clear the browser or switch browsers. Results registered only by an officer's scan (when the phone had no connection) carry the phone's own count. Manual (officer-assisted) claims use 3 spoken questions, not the 8-question quiz, so they are reported separately. Confirm this is good enough before using these figures as outcome measures.

Upload admin emails (CSV)
